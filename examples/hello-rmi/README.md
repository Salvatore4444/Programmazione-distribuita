# HelloWorld Java RMI

Esempio per le [domande 49–51](../../tutti%20appunti%20pratici/ESERCIZI%20HELLOWORLD%20RMI.md): progetti `server` e `client` separati, contratto in `shared-api`, esportazione esplicita con `exportObject()`, policy limitate a localhost e istruzioni per `rmic` storico.

I sorgenti del client usano solo `studio.Hello`, non `studio.HelloImpl`. Le directory `build` sono ignorate da Git.
